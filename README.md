# RYO ARCHIVE // lost files

コスプレイヤー遼さん（@sobaabura_）の投稿をリンクから閲覧する、ファンゲーム風のミニサイトです。

## 入っている機能
- 5問の選択式クイズ
- 正解すると6つの記録が順番に開放
- 記録カードからXの投稿／プロフィールへ移動
- ホラー演出（ノイズ、画面フラッシュ、ランダムメッセージ）
- 任意の効果音（初期状態OFF）
- スマートフォン／PC対応
- 外部画像ファイルを転載せず、Xのリンクで閲覧

## 起動方法
`index.html` をブラウザで開いてください。

## 公開方法（GitHub Pages）
1. GitHubで新しいリポジトリを作成
2. `index.html`、`style.css`、`game.js` をアップロード
3. Settings → Pages → Deploy from a branch → `main` / `/ (root)` を選んで保存

## 投稿リンクについて
最初の2件は確認できた投稿へのリンクです。残りは遼さんのXプロフィールへリンクしています。カードの追加・変更は `game.js` 内の `records` 配列を編集してください。
写真そのものはこのサイトに保存していません。投稿の公開状態やX側の仕様によっては閲覧にログインが必要な場合があります。

## 注意
ホラー演出は画面フラッシュとノイズ表現を含みます。効果音はユーザーがONにした場合のみ鳴ります。
